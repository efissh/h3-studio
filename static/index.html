安装 H3 Studio

电脑 Chrome / Edge：使用地址栏的安装图标，或打开浏览器右上角“⋮”菜单，选择“安装 H3 Studio”或“安装网页为应用”；如果没有安装提示，可在菜单中选择“将网页安装为应用”。

iPhone / iPad：在 Safari 中打开网页，点击“分享” → “添加到主屏幕”，并选择“作为网页 App 打开”。

Android：在 Chrome 中点击右上角“⋮” → “安装应用”或“添加到主屏幕”。

网页应用需要安全连接：本机的 http://127.0.0.1 可以直接安装；通过网络访问时请使用 HTTPS 地址（例如启用 Tailscale Serve 后的地址）。安装后仍需先启动 H3 Studio 并登录；不支持离线生成或离线访问视频。
